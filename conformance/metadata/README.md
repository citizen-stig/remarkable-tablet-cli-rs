# Document metadata conformance

Place cases under `<source-project>/<case-id>/`. Preserve complete document
context where available: `.content`, `.metadata`, `.pagedata`, page `.rm` files,
source PDF, templates, and archive layout. A `.content` file alone does not
provide a visual reference.

Start with remarquee and rmapi bundles. Expected results should identify ordered
live page IDs, source PDF page mappings, templates, orientation, and handling of
deleted pages, missing annotations, empty stroke files, and legacy filenames.

Label source PDFs as inputs; do not treat them as expected annotated exports.
See the [source catalog and attribution requirements](../README.md).
