# Tablet thumbnails

Store source inputs paired with tablet previews whose origin has been verified.
Initial candidates are eink-sync's `quicksheets-p2` and `quicksheets-p3` pairs.

Record native thumbnail dimensions and any resizing. These cases help detect
layout, pressure, and missing-ink regressions but cannot establish full-resolution
fidelity. See the [source catalog and attribution requirements](../../README.md).
